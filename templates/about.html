ABOUT THE PROJECT

Understand your VMs.

A simple, centralized view of a small virtual machine lab.

How it works

  1. A Python agent collects CPU, RAM, disk, network counters, and uptime with psutil.
  2. Each VM sends a JSON sample to Flask every {{ config.METRIC_INTERVAL }} seconds.
  3. SQLite stores samples and alert episodes.
  4. This dashboard polls the API and draws historical charts.

A hostname identifies one VM. Give cloned VMs unique hostnames or configure an agent hostname override.

Monitoring rules

CPU warning
> {{ config.CPU_THRESHOLD }}%
RAM critical
> {{ config.MEMORY_THRESHOLD }}%
Disk critical
> {{ config.DISK_THRESHOLD }}%
Offline critical
No sample for > {{ config.OFFLINE_TIMEOUT }} seconds

Offline means the server stopped receiving samples. It can indicate a stopped agent or a network issue as well as a powered-off VM.
